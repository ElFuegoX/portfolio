## ✨ Stack technique

| Couche | Technologie |
|---|---|
| Structure | HTML5 sémantique |
| Style | Tailwind CSS (CDN) + CSS custom |
| Typographies | Clash Display · Fraunces · Plus Jakarta Sans · JetBrains Mono |
| Animations | Lenis smooth scroll · IntersectionObserver · CSS transitions |
| Interactivité | Vanilla JS — dark/light mode, timeline laser, modales, scroll spy |
| Déploiement | GitHub Pages (100% statique) |

## 🌟 Fonctionnalités

- **Dark / Light mode** avec bascule dynamique du logo (orange braise ↔ bleu azur)
- **Sidebar fixe** avec navigation ancres, scroll spy actif, popover CV bilingue
- **Timeline laser** : la lumière progresse avec le scroll et allume les points au passage
- **Modal CV** : visionneuse PDF intégrée + téléchargement EN et FR
- **Lightbox photo** : agrandissement de la photo de profil
- **Reveal animations** : apparitions soyeuses à l'entrée dans le viewport
- **Responsive** : header mobile + drawer navigation
- **SEO** : balises Open Graph pour un aperçu soigné sur LinkedIn, WhatsApp, Discord
